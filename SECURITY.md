# Segurança

Não publique vulnerabilidades, credenciais ou dados pessoais em issues.

Envie o relato de forma privada para `marcosmendes.dev@gmail.com`, incluindo a área afetada, impacto observado e passos mínimos para reprodução. Não acesse dados de terceiros, não mantenha persistência e não realize testes destrutivos.

O projeto recebe correções na versão publicada mais recente. Dependências são revisadas pelo Dependabot e o CI valida tipagem, testes e build.
