# Como contribuir

1. Abra uma issue descrevendo a correção ou melhoria.
2. Crie uma branch curta e focada.
3. Não adicione dados pessoais, credenciais, `.env.local` ou materiais de cliente sem autorização.
4. Atualize a documentação quando alterar comportamento, instalação ou variáveis.
5. Execute `npm run typecheck`, `npm test` e `npm run build`.

O pull request deve explicar o problema, o resultado e como a alteração foi validada. Commits claros como `feat:`, `fix:`, `docs:` e `test:` facilitam a revisão.
